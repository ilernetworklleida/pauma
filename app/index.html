Palabras importantes

Palabras o expresiones que Pauma debería reconocer mejor. Útil para motes familiares, nombres propios, jerga del trabajo, palabras médicas...

Mi tarjeta de identidad sorda

Una pantalla diseñada para mostrar rápido a desconocidos en situaciones imprevistas (urgencias, mostradores, transporte). Todo se guarda solo en este móvil.

Modo presentación

Pantalla con texto enorme para cuando tú hables (charla, clase, reunión). Pauma muestra tu voz transcrita en letra grande para que tu audiencia te lea.

Aviso de transcripción

Por respeto a la persona con la que hablas, Pauma muestra brevemente que está transcribiendo. Puedes desactivarlo si te incomoda.

Mis datos

Backup completo en un archivo JSON (sesiones, personas, frases, ajustes). Útil si cambias de móvil.

Estadísticas

Solo de este dispositivo. No se envía a nadie.
